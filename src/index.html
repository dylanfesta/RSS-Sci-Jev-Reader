⚛ 3. About SmartRSSReader v0.1.0 Tauri
  • TypeSafe Jev Ranking: Evaluates binary noul (Yes/No probability) and multi-level score rubrics via OpenRouter's Decisions API (typesafe/jev-1.14), normalizing outcomes to [0.0, 1.0].
  • Instant Re-Weighting & Penalties: Positive weights boost relevant papers; negative weights (e.g. -1.0) penalize unwanted topics. Changing any weight re-ranks all papers offline immediately.
  • Incremental Memory & 30-Day Archive: Seen and archived papers are remembered by SHA-256 UID so updates only score genuinely new papers. Archived items older than 30 days are auto-pruned.
  • Historical Snapshots & Local Security: Editing or deleting a query preserves the exact snapshot on previously scored papers. Your API key is encrypted locally with PBKDF2-HMAC-SHA256 + AES-256-GCM.
